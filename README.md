# firebase_kravekitchen
Krave Kitchen is a Progressive Web App (PWA) that allows users to view, add, edit, and delete recipes. The app works both online (using Firebase Firestore) and offline (using IndexedDB), ensuring an easy experience for users.
Features:
-View recipes with images, ingredients, and instructions.
-Add new recipes or edit/delete existing ones.
-Works offline using IndexedDB.
-Automatically syncs offline changes to Firebase when back online.
-Responsive design using Materialize CSS.
-Installable as a PWA with offline caching via service worker.
